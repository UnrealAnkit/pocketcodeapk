● FAQ

Useful answers,
without the pitch.

Is PocketCode a cloud IDE? +

No. PocketCode remotely controls your existing local development environment.

Do I need VS Code? +

The current workflow uses the PocketCode VS Code extension and supports VS Code, Cursor, or compatible editors.

Does it work with AI coding agents? +

PocketCode is designed to monitor and interact with CLI coding-agent workflows around Claude, Codex, and Aider.

How does pairing work? +

Start a mobile session and scan the generated QR code.

Is PocketCode open source? +

Yes. The repository is public and MIT licensed.
